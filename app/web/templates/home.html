How a build gets here

  1. A prompt is screened, then wrapped as data inside a fixed builder prompt.
  2. One endpoint+model pair generates one self-contained HTML document; a prompt can fan out to up to four pairs at once.
  3. The document is extracted from whatever the model actually returned, then gated: single file, size ceiling, no external URLs, no <base>.
  4. Only then is it published — served from a separate origin with connect-src 'none', so an app can draw but cannot reach a network.
