# Pomodoro Timer

Build me a pomodoro focus timer.

25 minutes of focus, then a 5-minute break, then repeat. Big readable
countdown, start / pause / reset, and a clear visual difference between
focus mode and break mode. Count how many pomodoros I've completed
today, and update the browser tab title with the remaining time so I
can keep it in a background tab.

Rules: everything in one self-contained HTML file, no libraries, no
notifications — just a gentle visual flip when a phase ends.
