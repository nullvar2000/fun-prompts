# Palette Generator

Build me a color palette generator.

Generate five colors that actually go together — use one base hue and
derive the rest with color harmony (analogous, complementary, whatever
looks good). Show them as full-height swatches. Clicking a swatch
copies its hex code to the clipboard. Pressing the space bar generates
a fresh palette. Make it feel like a toy: fast, colorful, no forms.

Rules: everything in one self-contained HTML file, no libraries.
